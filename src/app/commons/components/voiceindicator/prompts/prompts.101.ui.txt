조건-피그마) 활용할MCP: CursorTalkToFigmaMCP(채널명: 1l059std)
조건-피그마) 참고할 공통컴포넌트 노드ID: 3:3398

조건-파일경로) 구현될 TSX 파일경로: src/commons/components/voiceindicator/index.tsx
조건-파일경로) 구현될 CSS 파일경로: src/commons/components/voiceindicator/styles.module.css

==============================================

핵심요구사항) MCP를 연동하여 피그마의 디자인을 그대로 소스코드로 구현할 것.

핵심요구사항) 다음 조건을 모두 만족하는 완전한 variant 시스템을 구현할 것.
            - state: 'default' | ‘sucess’ | ‘listening’ 

핵심요구사항) 소리 크기에 따라 동적으로 반응하는 variant 시스템 구현:
            - 외부에서 주입받는 Props: `audioLevel` (0 ~ 100 사이의 숫자값)
            - `audioLevel` 값에 따라 중간에 있는 막대 인디케이터 3개의 개별 높이가 각기 다른 CSS 변수로 제어되도록 구현할 것.

조건-CSS) CSS Module을 활용하여 인디케이터 막대 3개에 애니메이션 효과 구현:
    - @keyframes 애니메이션을 정의하여, 각 막대가 위아래로 자연스럽게 오르내리는 루프(loop) 효과를 기본적으로 적용할 것.
    - 컴포넌트 Props로 받은 `audioLevel` 값에 따라, 이 애니메이션의 속도(animation-duration)나 증폭 폭(transform scale 값)이 동적으로 변경되도록 구현할 것.
    - 소리가 없을 때(`audioLevel === 0`)는 정지된 세 개의 짧은 막대 상태(피그마 디자인과 동일)를 유지하도록 처리할 것.
