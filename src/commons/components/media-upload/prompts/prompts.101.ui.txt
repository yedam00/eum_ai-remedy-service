            - variant: ‘empty’ | ‘uploaded’
            - empty: 이미지가 업로드되기 전 상태 (플러스 아이콘 영역 표시)
            - uploaded: 이미지가 첨부된 상태 (상단/우측 'X' 삭제 버튼 표시)

핵심요구사항) Props 구성 (UI 확인용):
            - imageUrl (string, optional): 업로드된 이미지의 URL 경로
            - `imageUrl` 값이 존재하면 자동으로 'uploaded' 스타일로, 없으면 'empty' 스타일로 자연스럽게 전환되도록 화면을 구현할 것.
