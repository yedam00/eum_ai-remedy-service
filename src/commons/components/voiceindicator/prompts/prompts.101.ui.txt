기존요구사항-참고만) MCP를 연동하여 피그마의 디자인을 그대로 소스코드로 구현할 것.

기존요구사항-참고만) 다음 조건을 모두 만족하는 완전한 variant 시스템을 구현할 것.
            - state: 'default' | ‘sucess’ | ‘listening’ 

기존요구사항-참고만) 소리 크기에 따라 동적으로 반응하는 variant 시스템 구현:
            - 외부에서 주입받는 Props: `audioLevel` (0 ~ 100 사이의 숫자값)
            - `audioLevel` 값에 따라 중간에 있는 막대 인디케이터 3개의 개별 높이가 각기 다른 CSS 변수로 제어되도록 구현할 것.

기존요구사항-참고만) CSS Module을 활용하여 인디케이터 막대 3개에 애니메이션 효과 구현:
    - @keyframes 애니메이션을 정의하여, 각 막대가 위아래로 자연스럽게 오르내리는 루프(loop) 효과를 기본적으로 적용할 것.
    - 컴포넌트 Props로 받은 `audioLevel` 값에 따라, 이 애니메이션의 속도(animation-duration)나 증폭 폭(transform scale 값)이 동적으로 변경되도록 구현할 것.
    - 소리가 없을 때(`audioLevel === 0`)는 정지된 세 개의 짧은 막대 상태(피그마 디자인과 동일)를 유지하도록 처리할 것.            


기존요구사항-참고만) 1. 피그마 스펙 기반 두께(Thick) 수정:
            - VoiceIndicator 컴포넌트의 success 상태에서 아이콘/바의 선 두께가 피그마 스펙(8px)과 일치하도록 수정할 것. (현재 4px로 너무 얇게 렌더링되는 문제를 해결)

           2. 'success' 상태 체크 표시 애니메이션 구현:
            - `state="success"`로 전환될 때, 원형 배경 위로 체크 표시가 나타나는 애니메이션을 추가할 것.
            - 애니메이션 방식: 체크 표시의 패스가 왼쪽 하단에서 오른쪽 상단으로 마치 그려지듯(drawing animation) 부드럽게 나타나는 효과를 적용할 것.
            - 음성 인식이 완료되고 텍스트 변환에 성공했다는 의미가 시각적으로 명확하고 긍정적으로 전달되도록 자연스러운 인터랙션을 연결할 것.
