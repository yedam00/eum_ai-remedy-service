기존요구사항-참고만) MCP를 연동하여 피그마의 디자인을 그대로 소스코드로 구현할 것.

기존요구사항-참고만) 다음 조건을 모두 만족하는 완전한 variant 시스템을 구현할 것.
            - expanded: ‘False’ | ‘True’

기존요구사항-참고만) 컴포넌트에 사용될 <Checkbox /> 공통컴포넌트는 다음의 규칙을 지켜 step-by-step 으로 구현하고, 적용 결과를 체크리스트로 반환할 것.
                1) 모달에 사용될 <Checkbox /> 공통컴포넌트 원본을 수정하지 말고, 아래의 props만 활용할 것.
                    - state: default, selected를 확인하여 구현할 것.
                    - size: 피그마와 일치할 것.
                    - title (string, optional): 드롭다운 헤더 제목 (기본값: 피그마의 Title 프로퍼티 값)
                    - pointText (string, optional): 우측 선택 상태 텍스트 (기본값: "+3개 선택됨")

기존요구사항-참고만) 1. Checkbox 공통 컴포넌트 재사용 및 연결:
         - 드롭다운 리스트 내부 항목들의 체크박스 영역(checkboxSlot)을 단순 span 태그 대신 기존 공통 컴포넌트인 <Checkbox />로 대체하여 렌더링할 것.
         - 원본 Checkbox 컴포넌트 파일(src/commons/components/checkbox/index.tsx)을 불러와 재사용하고, 각 항목의 선택/해제 상태가 정상적으로 반영되도록 연결할 것.

기존요구사항-참고만) 2. chevronSlot 클릭 시 expanded 상태 상호 전환 (토글):
         - 상단 요약 바 우측의 화살표 버튼(chevronSlot) 클릭 이벤트를 연결할 것.
         - 접힘 상태(expanded: false)에서 chevronSlot을 클릭하면 펼침 상태(expanded: true)로 전환되어 리스트 항목들이 보이도록 구현할 것.
         - 펼침 상태(expanded: true)에서 chevronSlot을 클릭하면 다시 접힘 상태(expanded: false)로 전환되도록 양방향 토글 동작을 완성할 것.

핵심요구사항) 선택된 체크박스 수량 동적 반영 (pointText 연동):
          - 리스트 항목의 체크박스를 클릭하여 선택/해제할 때마다 선택된 항목의 총개수를 계산할 것.
          - 상단 헤더의 pointText 영역에 선택된 항목의 총개수에 따라 '+N개 선택됨' 형태의 텍스트가 실시간으로 업데이트되어 노출되도록 구현할 것. (예: 1개 선택 시 '+1개 선택됨', 0개 선택 시 텍스트 숨김 처리)
