핵심요구사항) 다음의 기능을 playwright 테스트를 활용하여 TDD기반으로 구현할 것.
            1) 테스트 제외 라이브러리
                - jest
                - @testing-library/react

            2) 테스트 조건
                - timeout은 설정하지 않거나, 500ms 미만으로 설정할 것.
                - /test-chatinput 페이지가 완전히 로드된 후 테스트할 것.
                    - 페이지 로드 식별 요구사항: 고정식별자 data-testid 대기 방법
                    - 페이지 로드 식별 금지사항: networkidle 대기 방법
		  * data-testid="file-dropzone" (file-upload 빈 영역)
                  * data-testid="hidden-file-input" (OS Native 파일 입력창)
                  * data-testid="multi-upload-filled-container" (multi-upload 채워진 영역)
                  * data-testid="file-preview-item" (개별 썸네일 미리보기)
                  * data-testid="file-add-more-placeholder" (multi-upload 내 추가 첨부 placeholder)
                  * data-testid="file-delete-button" (개별 파일 삭제 버튼)

핵심요구사항) 1. 사용자 시나리오 (User Journey)
                1. 사용자는 fileDropzone 영역(data-testid="file-dropzone") 클릭 시, OS Native 파일 선택 창(data-testid="hidden-file-input")이 불러와진다.
                2. 원하는 사진 또는 동영상 파일을 선택해 첨부를 완료한다.
                3. 파일 선택이 완료되면 화면은 multi-upload(filled) 모드(data-testid="multi-upload-filled-container")로 변경된다.
                4. 사용자는 첨부한 파일의 썸네일(data-testid="file-preview-item")이 개수에 맞게 표시되는 것을 확인한다.
                   - 최대 첨부 가능한 파일 개수는 6개이다. 
                5. 파일이 1개 이상 6개 미만일 때, multi-upload 베리언트에서 placeholder(data-testid="file-add-more-placeholder") 클릭을 통해 파일을 더 추가할 수 있다.
                6. 사용자가 개별 파일의 삭제 버튼(data-testid="file-delete-button")을 클릭하면 해당 파일이 목록에서 제거된다.
                7. 모든 첨부 파일이 삭제되어 0개가 되면 화면은 다시 file-upload (data-testid="file-dropzone") 상태로 돌아간다.
