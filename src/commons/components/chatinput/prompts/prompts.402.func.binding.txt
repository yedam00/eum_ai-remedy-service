		- <chatInput />의 각 variant에서 답변 버튼을 클릭하거나 이미지를 선택하여 전송했을 때, 상단 대화 영역에 사용자 메시지<SpeechBubble /> variant: user 형태로 바인딩되어 정상적으로 화면에 노출되는지 검증할 것.
		- 이미지를 선택하여 보낸 경우, 화면에 렌더링된 <speechBubble /> 컴포넌트가 variant: user, hasImage: true 상태로 동작하고 이미지 요소가 독립적으로 바인딩되는지 검증할 것.

기존요구사항-참고만) test-chatinput2 테스트 페이지 구현
	    1. Variant 순차 전환 및 Speech-Bubble 바인딩 (시퀀스 모드)
		- option-trio ➔ vertical-select ➔ medicine-search ➔ pain-scale ➔ checkbox-list ➔ file-upload 순서로 이어지는 Mock 질문 데이터 스태킹 상태를 생성할 것.
		- 하단 chatinput에서 답변 버튼 클릭(제출) 또는 이미지 선택후 다음 버튼 클릭 시:
		   1) 선택된 텍스트가 상단 대화 영역의 <speechBubble> variant:user 형태로 즉시 추가될 것.
		   2) 이미지를 첨부하여 제출한 경우, <speechBubble /> 컴포넌트의 props로 variant: 사용자(user), hasImage: true를 전달하여 이미지가 전용 UI로 노출되도록 구현할 것.
      		   3) 0.5초 타이머 후 다음 variant 질문으로 자동으로 전환될 것.
      		   4) 전환 시 messageinput의 placeholder 역시 해당 variant의 가이드 텍스트로 자동 반영될 것.

	    2. chatInput 컴포넌트의 varient별 placeholder 동적 바인딩
		- option-trio, vertical-select, medicine-search, pain-scale, checkbox-list 등 모든 variant의 상태에 따라, 해당 variant의 선택지 중 대표 텍스트(예: 첫 번째 버튼의 label)가 하단 messageinput의 placeholder 속성에 동적으로 바인딩되도록 구현할 것.
		- variant가 변경될 때마다 messageinput의 placeholder 역시 해당 질문/선택지에 맞게 자동으로 업데이트되어야 함.
