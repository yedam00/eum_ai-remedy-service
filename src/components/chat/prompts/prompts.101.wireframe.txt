핵심요구사항) 완성된 컴포넌트를 페이지에서 import하여 연결시킬 것.
                - 연결될 경로: src/app/chat/page.tsx

핵심요구사항) HTML과 flexbox를 활용한 와이어프레임 구조만 만들어낼 것.

핵심요구사항) 1. 전체 화면 Flexbox 가변 레이아웃:
  		- 전체 페이지는 화면 높이(100vh / 100dvh) 기준의 수직 Flexbox(Column) 레이아웃으로 구성할 것.
   		- 상단 영역: Header (62px 고정 영역)
   		- 중앙 영역: Content (대화 목록 스크롤 영역, flex: 1 적용하여 유동적 높이 확보)
   		- 하단 영역: ChatInput (유동형 서브 옵션 영역, height: auto 적용)

	   2. 하단 ChatInput 컴포넌트 교체(Slot) 구조 반영:
   		- 하단 입력 영역은 새로 와이어프레임을 그리지 않고, 이미 작성된 ChatInput 공통 컴포넌트를 가져와 삽입할 것.
   		- ChatInput 컴포넌트의 `uiType` 프롭(예: 'pain-scale', 'checkbox-list', 'option-trio' 등)에 따라 하단 옵션 영역의 높이와 형태가 동적으로 바뀌더라도, 전체 화면 레이아웃 깨짐 없이 중앙 대화 영역(content)의 높이가 유연하게 조정되도록 와이어프레임을 구성할 것.

	   3. 와이어프레임 뼈대 및 연결:
   		- 세부 CSS 디테일이나 복잡한 인라인 스타일 없이, HTML 태그와 Flexbox 클래스만을 활용하여 와이어프레임의 구조적 틀만 구현할 것.
